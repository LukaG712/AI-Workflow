# Vault Map Example

Copy this file to `vault_map.md` and edit it to describe your Obsidian vault structure.

## Folders

- **Projects/** — Active and archived projects, each in its own subfolder.
- **Notes/** — General notes, ideas, and reference material.
- **Journal/** — Daily and weekly journal entries.
- **Resources/** — Books, articles, and external references.
- **_ai/** — Output folder for AI-generated files.

## Note Types

- `[[Project Name]]` — Project overview notes with goals and status.
- `YYYY-MM-DD` — Daily journal entries.
- `Meeting - YYYY-MM-DD` — Meeting notes with attendees and action items.
- `Topic - Name` — Reference notes on specific topics.
